# 📊 Modelo de Dados - Dashboard Power BI de Inventário de TI

## 🗂️ Estrutura do Modelo de Dados

### Visão Geral

O modelo de dados segue o padrão **Star Schema** (Esquema Estrela), com:
- **3 Tabelas Fato:** Hardware, Licenças, Manutenção
- **1 Tabela Dimensão:** Calendário
- **Relacionamentos 1:N** entre tabelas

```
           Calendário
               ↓
           Hardware ←→ Manutenção
               
           Licenças
```

### Tabela 4: Calendário (Dimensão)

**Descrição:** Tabela de datas para análises temporais

**Origem:** Gerada via DAX

**Código DAX:**
```dax
Calendario = 
ADDCOLUMNS(
    CALENDAR(DATE(2020,1,1), DATE(2026,12,31)),
    "Ano", YEAR([Date]),
    "Mês", MONTH([Date]),
    "MesNome", FORMAT([Date], "MMMM"),
    "MesAno", FORMAT([Date], "MMM/YY"),
    "Trimestre", "T" & QUARTER([Date]),
    "Semestre", "S" & IF(MONTH([Date]) <= 6, 1, 2),
    "DiaSemana", WEEKDAY([Date]),
    "NomeDiaSemana", FORMAT([Date], "dddd"),
    "DiaAno", DATEDIFF(DATE(YEAR([Date]),1,1), [Date], DAY) + 1
)
```

**Colunas:**

| Coluna | Tipo | Descrição |
|--------|------|-----------|
| Date | Data | Data completa |
| Ano | Número | Ano (2020-2026) |
| Mês | Número | Mês (1-12) |
| MesNome | Texto | Nome do mês (Janeiro) |
| MesAno | Texto | Mês/Ano (Jan/23) |
| Trimestre | Texto | Trimestre (T1, T2, etc) |
| Semestre | Texto | Semestre (S1, S2) |
| DiaSemana | Número | Dia da semana (1-7) |
| NomeDiaSemana | Texto | Nome (Segunda-feira) |
| DiaAno | Número | Dia do ano (1-365) |

**Relacionamentos:**
- Calendario[Date] → Hardware[Data_Aquisicao] (1:N)
- Calendario[Date] → Manutencao[Data_Manutencao] (1:N)

## 📊 Colunas Calculadas Recomendadas

### Tabela: Hardware

```dax
Idade_Anos = 
DATEDIFF(Hardware[Data_Aquisicao], TODAY(), YEAR)
```

```dax
Dias_Garantia_Restante = 
DATEDIFF(TODAY(), Hardware[Garantia_Fim], DAY)
```

```dax
Categoria_Idade = 
SWITCH(
    TRUE(),
    Hardware[Idade_Anos] <= 2, "Novo (0-2 anos)",
    Hardware[Idade_Anos] <= 4, "Médio (3-4 anos)",
    "Antigo (5+ anos)"
)
```

```dax
Status_Garantia_Calc = 
SWITCH(
    TRUE(),
    ISBLANK(Hardware[Garantia_Fim]), "Sem Info",
    Hardware[Garantia_Fim] < TODAY(), "Vencida",
    Hardware[Garantia_Fim] <= TODAY() + 30, "Vence 30d",
    Hardware[Garantia_Fim] <= TODAY() + 90, "Vence 90d",
    "Em Garantia"
)
```

### Tabela: Licenças

```dax
Licencas_Disponiveis = 
Licencas[Quantidade_Adquirida] - Licencas[Quantidade_Utilizada]
```

```dax
Taxa_Utilizacao = 
DIVIDE(
    Licencas[Quantidade_Utilizada],
    Licencas[Quantidade_Adquirida],
    0
)
```

```dax
Status_Utilizacao = 
SWITCH(
    TRUE(),
    Licencas[Taxa_Utilizacao] > 1, "Excesso",
    Licencas[Taxa_Utilizacao] < 0.5, "Subutilizado",
    "Normal"
)
```

## 🎯 Grupos e Hierarquias Recomendadas

### Hierarquia Temporal

```
Ano
└── Trimestre
    └── Mês
        └── Data
```

**Uso:** Análise de evolução de aquisições

### Hierarquia Organizacional

```
Localização
└── Departamento
    └── Usuario
```

**Uso:** Drill-down de distribuição de ativos

### Hierarquia de Hardware

```
Tipo
└── Marca
    └── Modelo
```

**Uso:** Análise detalhada de equipamentos

### Agrupamento de RAM

**Colunas:** RAM_GB  
**Bins:**
- 0-8 GB: "Baixa"
- 9-16 GB: "Média"
- 17-32 GB: "Alta"
- 33+ GB: "Muito Alta"

**Uso:** Distribuição de configurações

## 🔍 Considerações de Performance

### Otimizações Aplicadas

1. **Tipos de Dados Otimizados:**
   - Textos curtos: Texto (não Texto Grande)
   - IDs numéricos quando possível
   - Datas sem hora (Date, não DateTime)

2. **Relacionamentos Unidirecionais:**
   - Maioria 1:N unidirecional
   - Bidirecional apenas quando necessário

3. **Colunas Calculadas vs Medidas:**
   - Idade: Coluna calculada (usada em slicers)
   - Totais: Medidas (mais eficiente)

4. **Índices Automáticos:**
   - Power BI cria índices em colunas de relacionamento
   - Otimiza queries automaticamente

### Estimativas de Tamanho

**Com dados de exemplo (50 HW + 30 LIC + 40 MAN):**
- Tamanho do arquivo .pbix: ~500 KB
- Memória RAM usada: ~5 MB

**Projeção para dados reais (1000 HW + 200 LIC + 500 MAN):**
- Tamanho estimado: ~5-10 MB
- RAM estimada: ~50 MB

## 📝 Documentação de Negócio

### Regras de Negócio Implementadas

1. **Status de Ativo:**
   - Ativo: Em uso operacional
   - Inativo: Armazenado/não em uso
   - Manutenção: Em reparo
   - Descartado: Baixado do inventário

2. **Garantia:**
   - Vencida: Data_Fim < Hoje
   - Vencendo: Data_Fim entre Hoje e Hoje+90
   - Ativa: Data_Fim > Hoje+90

3. **Licenças:**
   - Compliance OK: Utilizada ≤ Adquirida
   - Risco: Utilizada > Adquirida
   - Subutilizada: Utilizada < 50% Adquirida

4. **Manutenção:**
   - Preventiva: Manutenção programada
   - Corretiva: Reparo de falha
   - Upgrade: Melhoria de configuração

### KPIs de Negócio

| KPI | Fórmula | Meta | Frequência |
|-----|---------|------|------------|
| Taxa de Ativos Ativos | Ativos/Total | >85% | Mensal |
| Garantias Vencidas | Count(Vencidas) | 0 | Semanal |
| Taxa Uso Licenças | Usadas/Total | 80-95% | Mensal |
| Custo Manutenção/Ativo | CustoTotal/Ativos | <10% valor | Trimestral |
| Idade Média Parque | Média(Idade) | <3 anos | Semestral |

## 🔄 Processo de Atualização

### Atualização de Dados

**Frequência Recomendada:**
- **Hardware:** Semanal (nova coleta via script)
- **Licenças:** Mensal (revisão manual)
- **Manutenção:** Diário (registro contínuo)

**Passos:**
1. Executar scripts de coleta (PowerShell/Python)
2. Atualizar arquivos CSV
3. No Power BI: Atualizar (Ctrl+R)
4. Validar dados
5. Republica (se em Service)

### Versionamento

**Convenção de nomes:**
```
Dashboard-Inventario-TI_v1.0_YYYYMMDD.pbix
```

**Exemplo:**
```
Dashboard-Inventario-TI_v1.0_20260115.pbix
```

## 🆘 Troubleshooting do Modelo

### Problema: Relacionamento não funciona

**Causa:** Tipos de dados diferentes
**Solução:** 
```
- Verifique ambas as colunas são Texto
- Ou ambas Número Inteiro
- Converta se necessário no Power Query
```

### Problema: Medida retorna BLANK()

**Causa:** Contexto de filtro vazio
**Solução:**
```dax
Medida = 
VAR Resultado = [SuaMedida]
RETURN IF(ISBLANK(Resultado), 0, Resultado)
```

### Problema: Desempenho lento

**Causa:** Muitas colunas calculadas
**Solução:** Converta para medidas quando possível
